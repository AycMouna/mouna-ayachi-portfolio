# Mouna Ayachi Portfolio

Editorial portfolio website in French with a vibrant EPSI-inspired palette, portrait hero, project cards, responsive layout, scroll reveal, hover motion and light/dark theme toggle.

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Customization
- Portrait: `public/mouna-portrait.png`
- Project images: `public/images/`
- Website text/content: `src/App.jsx`

A CV PDF can be placed at `public/cv.pdf` and the CV link updated from `/cv.pdf` if needed.
